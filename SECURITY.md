# Security

Milo runs in a home and talks to children's family members, so security reports matter.

**Do not open a public issue for a vulnerability.** Use GitHub's private reporting:
https://github.com/juancer/milo/security/advisories/new

Include what you found, how to reproduce it and what it lets an attacker do. Expect an answer
within a week. How Milo protects secrets, the admin UI and Telegram is in
[docs/security.md](docs/security.md).
